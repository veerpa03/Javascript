14. Question: What is the output of the following code?

let obj = { a: 1 };
let obj2 = { a: 1 };
console.log(obj == obj2);
Answer: false

Explanation: In JavaScript, objects are compared by reference, not by value. Even though obj and obj2 contain the same key-value pair, they are different objects in memory, so the comparison obj == obj2 returns false.
